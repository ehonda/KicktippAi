## Confirmed open review findings

The final reviewer was interrupted before completing the pass. Treat the list as a minimum; additional issues may remain.

### High: cached Bundesliga predictions bypass provenance

- Normal Matchday submits a cached prediction after reading only the prediction, without requiring metadata/manifest: `src/Orchestrator/Commands/Operations/Matchday/MatchdayCommand.cs` around line 282.
- Repredict and Verify currently treat null metadata as not outdated around Matchday line 924 and `VerifyMatchdayCommand.cs` line 317.
- Require validated metadata plus a canonical resolved manifest before any cached 2026/27 submission. Null/missing/corrupt metadata must be outdated or blocked. Cover normal, cancelled, and reprediction paths.

### High: ordinary context versions are not immutable enough for reconstruction

- `FirebaseContextRepository.SaveContextDocumentAsync` allocates `latest + 1` outside a transaction and writes with overwriting `SetAsync` (`src/FirebaseAdapter/FirebaseContextRepository.cs`, around lines 34-75). Concurrent different writers can reuse and overwrite one version.
- `UpdateContextDocumentVersionAsync` mutates nonreserved historical versions (around lines 259-289).
- Exact reads do not validate the stored competition/community/name/version envelope (around lines 145-155).
- ADR-0020 manifests currently store no ordinary-document content hash, so later reconstruction can silently use changed bytes.
- Establish a collision-safe immutable ordinary-document contract, validate scope envelopes, and durably bind content identity (hash or equivalent). Add concurrency, corrupt-scope, and post-prediction mutation tests. This likely needs a successor ADR.

### High: prepared 2026/27 artifacts are not loadable end to end

- `PreparedExperimentCommandSupport` loads JSON with stock `System.Text.Json`, while `ResolvedMatchContextManifest` has a private constructor/get-only properties and no converter. A populated artifact cannot deserialize.
- Add an explicit safe serialization contract/converter and a real file round-trip test with a valid populated manifest.

### High: prepared experiment competition/scope can bypass immutable reconstruction

- External competition is checked ordinally without canonicalization; run metadata can override competition/community without equality validation; executor routing also branches ordinally.
- A case variant or scope override can reach the legacy timestamp path.
- Canonicalize once, require artifact/manifest/run-metadata scope equality, and test case variants and malicious/mistaken overrides.

### High: prepare commands do not source provenance

- The four prepare command families currently construct items without `ResolvedContextManifest` and `PredictionCreatedAt`, so 2026/27 artifacts are rejected rather than executable.
- The WIP task text defers automatic provenance sourcing to P1-06. Decide explicitly whether P0-12's accepted contract permits only fail-closed manually populated artifacts or requires prepare commands to load a referenced stored prediction now. Keep the decision in an ADR/task record, not only code. In either case, prove one successful file-backed 2026/27 recorded reconstruction after publication heads advance.

### Medium: on-demand exact reread does not verify the requested version

- `BundesligaMatchContextResolver` checks content/name/nonnegative version after save/re-read but does not require `returned.Version == requestedVersion` (around lines 167-194).
- Add the equality check and a corrupt-repository regression test.
