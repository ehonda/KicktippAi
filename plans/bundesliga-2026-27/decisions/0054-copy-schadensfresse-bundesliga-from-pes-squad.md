# ADR-0054: Copy schadensfresse Bundesliga predictions from pes-squad

- Status: Accepted
- Date: 2026-08-27
- Accepted by: Project Owner on 2026-08-27

## Context

ADR-0052 selected `schadensfresse` as an independent Sol/`xhigh` primary while
the community administrator was still preparing its 2026/27 season. Once the
season became visible, the current rules showed that ordinary Bundesliga
matches use the same 2/3/4 scoring and 90-minute result boundary as
`pes-squad`. The community also includes the DFB-Pokal and Champions League,
whose results are evaluated after a penalty shootout, and Champions-League
bonus questions with later deadlines. Those mixed-competition exceptions do
not apply to the opening Bundesliga matchday or its common Bundesliga bonus
round.

The established reference-copy path reads the exact stored model identity and
immutable context from `community_context`. Match copies fail closed if the
fixture or provenance differs. Bonus copies additionally require ADR-0048's
exact normalized question, selection-limit, and complete-option-set
compatibility. An ordinary bonus incompatibility generates exactly once in the
target community context; invalid or ambiguous state fails closed.

The Project Owner chose the copy topology for ordinary Bundesliga work and
explicitly kept the mixed-competition exception as P1 work. Manual live
validation remains required before recurring schedule inclusion.

## Decision

For the currently supported `bundesliga-2026-27` runtime:

- `pes-squad` remains the sole independent Sol/`xhigh` production reference.
- The `schadensfresse` matchday and bonus entrypoints post to
  `community: schadensfresse` with the target's own credential pair but read
  `community_context: pes-squad` using the exact production model, prompt,
  cap, service-tier, and immutable provenance identity.
- Ordinary Bundesliga match copying binds to the exact canonical
  `community-rules-pes-squad.md` source identity. The P0 published
  `community-rules-schadensfresse.md` content is intentionally identical so
  the two supported Bundesliga contexts do not present different scoring
  instructions.
- `schadensfresse-context-collection.yml` remains target-owned with
  `community_context: schadensfresse`. It publishes
  `community-rules-schadensfresse.md` and the target's other context so an
  ADR-0048 bonus incompatibility can switch safely to independent target-
  context generation.
- The complete live target contract is documented here rather than injected
  into the P0 Bundesliga prompt: tips hidden until the deadline; exact-score
  mode; Bundesliga after 90 minutes; DFB-Pokal and Champions League after
  penalty shootout; tie-break by matchday wins unless otherwise agreed;
  zero-minute lead; 2/3/4 match scoring (win 2/3/4 and draw 2/-/4); and four
  points per correct bonus answer with answer order ignored.
- Eight questions are currently open. Five Bundesliga questions are due
  `2026-08-28T18:30:00Z`; three Champions-League questions are due
  `2026-09-09T10:00:00Z`. The first manual bonus caller pins an optional,
  inclusive strict-UTC ceiling to the first timestamp. The reusable default is
  empty, while an explicit ceiling selecting zero questions fails visibly.
- The five due Bundesliga target questions differ from `pes-squad` only by
  five audited full texts beginning `1.BL: `. A fail-closed resolver applies
  only to the exact tuple `bundesliga-2026-27` / `schadensfresse` /
  `pes-squad` and those five full texts. It projects canonical source text only
  for source lookup, compatibility mapping, and source freshness. It does not
  weaken ADR-0048 normalization or alter the real target question used for
  context, fallback, persistence, POST, verification display, or provenance.
- Alias IDs plus source/target normalized-text hashes and projected
  compatibility hashes are trace metadata. The existing target compatibility
  hash remains the raw target hash.
- A cutoff-scoped POST preserves every current non-target bonus select value,
  because Kicktipp submits the complete form and a partial payload must not
  erase later Champions-League answers.
- The three later Champions-League questions are not generated by this P0
  dispatch. They need question-specific competition, prompt, and context
  routing before their September deadline; an unfiltered target fallback is
  not accepted as implicit mixed-competition operation.
- No DFB-Pokal or Champions-League match may reuse a Bundesliga source
  prediction. P1-08 owns competition-aware detection and temporarily switching
  `schadensfresse` to primary mode for those finals, plus explicit handling and
  scheduling of its Champions-League bonus questions.
- This repository change leaves all schadensfresse leaf callers manual-only and
  leaves ADR-0053's recurring outer lane unchanged. P0-21 must first complete
  read-only readiness, target-owned context collection, match copy, bonus
  compatibility/fallback observation, and payload-safe Kicktipp/Firestore/
  Langfuse inspection. Recurring inclusion follows only through a separately
  reviewed schedule change after that evidence is green.

## Alternatives considered

- **Keep schadensfresse independent for all predictions:** Rejected because it
  would spend a second model call for ordinary Bundesliga fixtures whose
  scoring contract matches the established reference community.
- **Use the schadensfresse context while calling the row a copy:** Rejected
  because the stored prediction and immutable provenance would then have a
  different context identity; the copy source must be exactly `pes-squad`.
- **Publish mixed-competition clauses in the P0 Bundesliga prompt:** Rejected
  because the supported copy path should present the same canonical Bundesliga
  rules as its source. ADR-0054 and P1-08 preserve the complete target contract
  until competition-aware prompt/context routing exists.
- **Implement mixed-competition switching in P0:** Rejected because those
  finals and later Champions-League bonus deadlines do not block the opening
  Bundesliga predictions. P1-08 records the work explicitly.

## Consequences

- Compatible Bundesliga match and bonus predictions add no model call for
  `schadensfresse`.
- A current mapped Bundesliga bonus mismatch remains observable and bounded:
  it generates once using the target-owned schadensfresse context rather than
  contaminating the `pes-squad` source identity.
- P0 publishes one canonical Bundesliga rule identity; this ADR and P1-08 make
  the mixed target contract explicit without feeding it to Bundesliga copies.
- Production schedule inclusion remains gated on the complete live ladder; this
  decision alone authorizes neither a dispatch nor a schedule mutation.
- The September Champions-League bonus boundary and later DFB/CL match-finals
  boundary are visible P1 work instead of latent incorrect copy assumptions.
